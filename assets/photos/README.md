# Photos

Déposer ici les photos du restaurant. Le site les cherche sous ces noms
(tant qu'un fichier manque, la page affiche un cadre « Photo à ajouter ») :

| Fichier            | Où sur la page                 | Format conseillé            |
|--------------------|--------------------------------|-----------------------------|
| `salle.jpg`        | Le restaurant, grande photo    | portrait 4:5, ~1200 px      |
| `plat-01.jpg`      | Le restaurant, petite photo    | carré, ~900 px              |
| `terrasse-vue.jpg` | La terrasse, bandeau           | panoramique 21:9, ~2000 px  |
| `terrasse-01.jpg`  | La terrasse, table dressée     | paysage 3:2, ~1200 px       |
| `plat-02.jpg`      | La terrasse, plat              | portrait 4:5, ~900 px       |

JPG à 80 % de qualité, 300 Ko maximum par image pour garder le site léger.
